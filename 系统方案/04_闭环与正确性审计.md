# 沃朗租赁系统 · 闭环与正确性审计报告（含修复记录）

> 版本：v1.0　|　日期：2026-08-07
> 说明：本报告对应目标任务②（每功能是否闭环）与③（逻辑/数据正确性）。由两名独立审计员盲审 UI 原型 + 业务流文档 + 设立方案书真相源，发现问题已在本轮 UI 优化中修复。

---

## 一、闭环审计（对照业务流文档第七部分 12 条闭环校验点）

**审计结论**：优化前正向流程 ≈100%，但**逆向路径（红冲/退货/作废/变更/调整单/收回再流转/还款恢复）成体系缺失**，闭环度约 55%。ERP 死穴全在逆向。

**已修复（补进 UI 的逆向/亮灯）**：

| # | 缺口 | 修复（落到 UI） |
|---|---|---|
| P0-1 | 收租无红冲/退款 | 收租页加「红冲/退款/协商延期」逆向面板 + 「钱该动没动」稽核（到期未生成/已到账未核销/缺凭证） |
| P0-2 | 凭证无红冲连锁 | 凭证中心加「红冲连锁·锁账补导」总枢纽表 + 影响清单确认 + 上期调整承接 |
| P0-3 | 合同无作废/变更 | 合同页加「变更(提前结清/续租→重算)」「作废(限未采购·整份红冲)」+ 勾稽校验行 |
| P1-1 | 采购无退货 | 采购页加「退货→采购红冲+应付红字」「到货不符拒收留痕」 |
| P1-2 | 转让无收回分支 | 转让单加「客户放弃→转收回待处置」按钮 |
| P1-3 | 设备状态机断 | 资产状态机加逆向旁支「收回待处置→再投放/二手/报废」 |
| P1-4 | 逾期无还款恢复 | 逾期案加「已还款·关闭恢复」按钮 |
| P1-5 | 盘点差异不闭合 | 盘点差异加「生成盘盈亏调整单」 |
| P1-6 | 供应商单一依赖灯缺 | 供应商池加「单一依赖预警」条 + 淘汰/停用留痕说明 |
| P1-7 | 风控拒绝/降级缺 | 客户详情加「评级下调预警」「准入拒绝留痕」 |
| P1-9 | 报价不达标态不显 | 报价测算加红色「不达标→生成合同置灰·退回重算」反例态 |

**修复后闭环度**：逆向覆盖由 ~25% 提升到 ~75%，整体闭环度约 **85%+**。

## 二、正确性审计（对照《设立方案书 V14.0》真相源 + 跨页勾稽）

**审计结论**：单页算术勾稽扎实、忠于设立方案书定价表/速算系数/三层回报/税务口径；主要问题是**"单台/合同口径"错乱**（设备页把播种墙当 9千/台、20台=一份合同，与设立方案书 18万/台冲突 20×），并牵出跨页不一致。

**已修复**：

| # | 问题 | 修复 |
|---|---|---|
| P0-1 | 设备口径 20× 错乱 | 全系统统一「1 台播种墙=市场价20万/集采18万」；合同 HT-018=1 台；采购/设备 BOM 全部改为万元口径（钢构14万+电控2.6万+传感1.1万+其他0.3万=18万），残值 2万，与供应商页一致 |
| P0-2 | 管理费档与回报矛盾 | 加权回报统一 25.0%（对齐设立方案书 §11：25%→10%档→可分配45万），驾驶舱/现金流/月报一致 |
| P1-1 | 已收期数打架 | 截至 08-06、期7未到 → 统一为已收 6 期 ¥40,320（合同/月报/设备累计一致） |
| P1-2 | 逾期口径不一 | 全系统逾期统一 ¥5,181 / 1 户 |
| P1-3 | 转让价矛盾 | 到期清单 HT-2025-006 播种墙×5 转让价改 ¥100,000（5×2万）；ZR-004 单台 ¥20,000 |
| P1-5 | 临期品类对不上 | 驾驶舱到期改「播种墙×5 / 货架1批」与转让清单一致 |
| P1-6 | 在租天数与期数矛盾 | 设备起租日/在租天数改为与 6 期自洽（158 天） |
| P1-7 | 客户计数不符 | 客户池与销售管道计数统一（共 115 家 · 潜客58/在租42/流失15） |
| P1-8 | 驾驶舱现金流混利润 | 「钱的去向」改为净现金流 −¥56,400（利润与现金分离，可分配另标） |
| P2-1/5 | 差价/所得税表述 | 集采差价标 2万·净利1.9万；企业所得税按净利50,000×5%=¥2,500 |

**修复后**：跨页数字口径统一到设立方案书，主要不一致清零。

## 三、已闭环 / 已对齐（通过项摘要）

- ✅ 速算系数、月租、期末转让率、三层回报、账期→回报、集采贡献、分配机制、税务口径、出资结构 —— 均与设立方案书一致。
- ✅ 先签约后采购、500万红线、留存≥20万、本金回报≥IRR门槛、禁"融资租赁"、权限保密隔离 —— 亮灯/校验落地。
- ✅ 单笔 P&L、收租三口径、押金/账龄/集中度 —— 单页勾稽闭合。

## 四、结论
经两轮盲审 + 本轮修复，系统在**闭环性**（补齐逆向路径与亮灯）与**正确性**（统一单台口径、修跨页不一致）两个维度显著提升，具备进入 Phase 0 正式立项的质量基础。仍建议开发前锁死一条：「1 台设备真实价 + 1 份合同几台」的后端建模口径，避免继承任何单位歧义。
