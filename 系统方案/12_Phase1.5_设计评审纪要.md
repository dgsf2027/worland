# 沃朗科技租赁板块 · Phase 1.5 设计评审纪要

> 版本：v1.0　|　日期：2026-08-08　|　评审对象：DESIGN_DOC v0.1 + ADR-001 + 业务流说明书
> 评审方式：4 角色独立盲审（工程卓越 / 检测与安全 / 数据真实性审计 / CIO 定价方法论）+ 主控合并去重 + 对抗验证。
> 总裁决：**有条件通过（Conditional Pass）**——业务流/状态机/闭环/逆向的**逻辑设计已达标**（可作 Phase 2 功能地图）；但**物理数据模型、服务端安全、价值定价方法论**有 8 条 P0，须以 **DESIGN_DOC v0.2 补丁 + Phase 2 强制 ticket + 上线红线** 形式钉死后，方可进 Phase 2 拆解。

---

## 一、亮点（正面锚点·别动）
- **层级①本金回报率作投放审批闸**（不达标不给签）——与设立方案书 4.4 逐字对齐，全案最专业处。
- **税务合规护栏**（禁"融资租赁"字段校验 + 分期收款销售 + 500万强制转一般纳税人预警 + 禁名义转让价）——命门守住。
- **AI 只起草、规则引擎出数字**——月报数字来自六件套(package_json)，AI 仅起草 analysis_json，边界清晰。
- **口径值干净**：目标 IRR/速算系数/管理费率/转让率/税率全部字段承载、无硬编码；逐件建档 20万/18万双字段落地、无 20× 残留。

## 二、P0 清单（8 条 · 已对抗验证为真 · 进 Phase 2 前必修）

### 数据模型（工程卓越 + 数据审计）
- **P0-A `transfer_order.asset_ids` 违反第一范式** → 拆 `transfer_order_line(transfer_order_id, asset_id, book_value, transfer_price, gain, voucher_id)`，与 `contract_asset` 同构，支撑逐台处置/部分转让/单台损益。
- **P0-B `book_value` 无折旧写手 + `rent_schedule` 错标 Odoo `account.asset.line` + book_value 装不下双账** → ①补 `asset_depreciation_line(asset_id, book, period_no, depr_amount, book_value_after, voucher_id)` 作折旧真相源；②`rent_schedule`＝应收/收款计划（≠折旧），`account.asset.line` 对应的是新增折旧表，措辞更正；③`book_value/residual_value` 明确账套口径（建议只在**经营口径 ops 账**体现，税务账走应收）。→ **新增 ADR-004**。

### 服务端安全（检测与安全）
- **P0-C 占位头 `X-User-*` 可任意伪造** → 后端只信任**可信网关注入**的 X-User-\*，网关必须**剥离客户端自带头再重注入**（写进部署拓扑 + ADR-001 上线红线）。
- **P0-D 敏感写操作缺 RBAC 矩阵** → 补「敏感操作 × 角色」权限矩阵（红冲/作废→财务+老板；分配→财务；投放审批→老板；淘汰→供应链主管+老板），挂**统一鉴权切面**（非散在 Controller）；留痕≠管控。
- **P0-E 行级+字段级隔离只在声明层** → 隔离在**服务端 DAO/DTO 层强制**（成本价/账期/分配/gain 走按角色 DTO 投影），月报按角色分别落库/渲染禁单 blob 下发；**解决占位期 user_id=0 隔离失效**：用 `X-User-Name` 解析真实 user 主键做隔离键，或明确"隔离随真 SSO 才生效、占位期不开放多用户"（二选一写进 ADR）。
- **P0-F 红冲连锁缺原子性/幂等/锁账守卫** → 红冲连锁在**单事务**内完成失败整体回滚；逆向写接口带**幂等键**（`reverses_id` 唯一约束 + 幂等 token）；服务端硬守卫：任何落在 `locked_period` 的凭证写一律拒绝，只走显式"上期调整"单。

### 定价方法论（CIO）
- **P0-G 价值定价缺核心输入"月替代人工价值/月节省"** → `asset`/品类档增 `monthly_labor_value`、`replace_headcount`、`self_purchase_payback = market_price / monthly_labor_value`；报价器设为**必填**；落两道校验：①品类准入 `payback ≤ 18 个月`（超阈值亮"吸引力不足"）；②客户净收益 `月节省 − 月租 > 0` 且保留承租方一定比例节省。否则"宣称价值定价、实际裸奔 IRR"＝对老板/LP 误导。
- **P0-H 层级②账期兑付缺口无预警（流动性暴雷点）** → `payable`（尾款）到期 T-N 天，规则引擎比对"该账期对应设备的在租/逾期/空置 + 未来 N 月回款 + 可动用留存"，`应付到期 − 可用回款 − 可动留存 < 0` → 亮**"账期兑付缺口"红灯 + 裁决人 + 补款来源**。这是层级②杠杆的刹车片。

## 三、P1 清单（Phase 2 期间必做）
| # | 来源 | 问题 | 修法 |
|---|---|---|---|
| P1-1 | 工程+数据 | `rent_schedule.status` 与 `rent_bill.status` 双写 | `rent_bill` 为收款真相源，schedule 状态由核销事件单向回写/退化为 join |
| P1-2 | 工程+CIO | `contract_asset` 缺单台租金分摊 | 加 `alloc_rent`/`alloc_ratio`（单一真值）；`contract.month_rent`=合同合计口径注明 |
| P1-3 | 工程 | 缺表 | 补 `maintenance`/`stocktake`+`stock_diff`/`contract_change`(含 reverse)/`accounting_period`；合同 status 补"已作废" |
| P1-4 | 工程 | 隔离列没落核心单据表 | `contract/asset/purchase_in/voucher/distribution` 统一加 `project_id`(+必要 owner_user) |
| P1-5 | 数据 | `residual_value` 无 @owner | 标 @owner 或改 `_helpers` 即时算（推荐即时算防 stale） |
| P1-6 | 数据 | 回报归因少残值第四源 | 补"残值回收 W%"，四源之和=总 IRR；厘清"三层杠杆"vs"四源利润"术语 |
| P1-7 | 工程 | `distribution/run` 无幂等无逆向 | 按 period 幂等 + 冲销/重算 API |
| P1-8 | 工程 | 双分录引擎复用 vs 重造未定 | 明确：复用凭证过账 Service + 板块专属 `yc_rent_` 表 |
| P1-9 | 工程 | `current_holder_customer_id` 派生无写手 | 即时算或由合同生效/关闭事件唯一维护并写进 @writes |
| P1-10 | CIO | "≤市场价"校验口径矛盾（客户总付本就>市场价） | 改为"月节省>月租"（客户每月正现金收益） |
| P1-11 | CIO | 速算系数当真值风险 | 系数仅作**起价建议**，层级①IRR 必用**真实集采成本/残值/账期重算** |
| P1-12 | CIO | IRR 未指定税后口径 | 显式税后（1%增值税+12%附加+5%所得税），冲刺0 逐格对平定价表 |
| P1-13 | CIO | 客户总付勾稽含押金错 | 改 `期数×月租 + 转让价 = 客户总付`；押金另走保证金科目（mockup 已对，业务流文档流程4 待改） |
| P1-14 | CIO | 杠杆临界点风控缺 | 层级③投放前校验 `资产回报 − 融资成本 ≥ 安全边际` + 负债率/融资额度上限 |
| P1-15 | CIO | 留存下限固定20万未随账期 scale | `留存 ≥ max(20万, 未来3月供应商净应付)`（与 P0-H 同源） |
| P1-16 | 安全 | 审计留痕身份不可信 | 留痕存网关注入身份+请求指纹；高危操作留痕只追加不可编辑 |
| P1-17 | 安全 | 导入中心注入/越权直写绕事件流 | 导入走同一校验+事件流通道，禁直写派生/隔离字段，单元格公式转义，owner/project 归属校验 |
| P1-18 | 安全 | 禁"融资租赁"仅卡枚举 | 扩到合同自由文本/附件关键词拦截+人工复核 |
| P1-19 | 安全 | 名义价转让"只亮灯" | 设硬阈值守卫：`transfer_price < book_value 或 < 市场价×下限` 强制升级审批+记录理由 |
| P1-20 | 安全 | 合同/现场照对象存储访问控制未定义 | 短时效签名 URL + 服务端鉴权代理，禁公开桶/可枚举 key |

## 四、P2（完善项 · 摘要）
命名统一 `reverses_id`；`customer.phase` 拆 `crm_stage`(人工)+运营态(派生)；`voucher_line` 补借贷方向+金额；押金全生命周期建模(收/退/期末抵转让价)；**`rule_config` 版本化配置源**（管理费阶梯/转让率/税率带生效期，税率注意 2027-12-31 sunset）；500万取**税务账**口径计算；AI 上下文喂入前脱敏；`user_role_ext` 写权限限老板+入 audit；新品类 35% 档纳入枚举；融资成本参数化；坏账拨备计提规则(参照 16.2万/10年)；押金覆盖率监控。

## 五、上游反馈
设立方案书 L123 品类准入表"10 万元 约 16,667 元"疑为"**30 万元**"笔误（30万÷18≈16,667，与 10万行重复）——设计未抄此错，建议回传方案书作者更正。
