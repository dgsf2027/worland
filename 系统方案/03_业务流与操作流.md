# 沃朗科技 · 业务流 / 操作流说明书

> 版本：v1.0　|　日期：2026-08-07
> 用途：把沃朗的经营逻辑拆成"可被系统承接"的**业务流程 + 操作流程 + 状态机 + 单据流**，作为把系统从 80 分优化到 100 分的**依据文件**。
> 口径真相源：《设立方案书 V14.0》《回报测算与定价模型》；设计 DNA：园区小卖账房设计七律。
> 架构约束：**不改架构、不改总体设计**——仍是智慧园区平台下的租赁板块，17 页结构不变；本文只把每条流"走完整、走闭环"。

## 第一部分 · 业务全景与角色

### 1.1 一句话业务
沃朗集采仓储设备（货架/阁楼/播种墙）→ 按客户"省下的价值"定价 → 分期收租 → 租满按残值转让给客户；靠**集采差价 + 资金时间价值 + 价值定价空间 + 残值**四份钱盈利，用**供应商账期**做无息杠杆放大回报。

### 1.2 角色与系统边界
| 角色 | 在系统里干什么 | 看不到 |
|---|---|---|
| **供应链管理**（李工等） | 开发/比价供应商、录合同、对接客户、下场做 BOM、配合催收 | 合伙人出资/分配、他人项目成本（保密隔离） |
| **财务** | 报价核算、凭证、双账、月度结账、分配、报表 | — |
| **老板 / GP（数智云仓·小洪）** | 审批（300万内自主）、月度过报告、决策 | — |
| **合伙人（LP）** | 不操作系统；每月收《月度报表》（按角色发放） | 运营明细、上下游成本价 |
| **系统（规则引擎）** | 自动生成租金计划/收租单/凭证/报表、算回报、亮灯预警 | AI 只起草叙述，永不算数字 |

### 1.3 业务对象（名词，均可下钻详情页）
供应商 · 客户 · 设备（逐件）· 合同 · 租金计划 · 收租单 · 采购单 · 转让单 · 维修工单 · 凭证 · 分配单 · 月度报表。

## 第二部分 · 主业务流（端到端）

**一台设备 / 一份合同的一生**（飞轮，↺ 复投）：

```
① 选品      → 判品类：市场价 ÷ 月替代人工价值 ≤ 18 个月？否→不做
② 开发供应商 → 四维比价·谈集采价(≥10%)·谈首付账期(层级②杠杆)
③ 客户需求   → 承接需求·限定品类
④ 报价测算   → 价值定价+速算系数→月租；算三层回报；本金回报≥目标IRR？否→不允许签
⑤ 风控准入   → 客户盈利/现金流评估·授信·押金；不过→不合作
⑥ 签约      → 不可撤销长约·自动生成租金计划表(N期)·期末转让价约定
⑦ 采购集采   → 先签约后采购·下采购单·首付/账期→应付
⑧ 入库投放   → 逐件编号建档·交付起租·押金入账
⑨ 按月收租   → 到期自动生成收租单·到账核销·收入凭证
   └(逾期)   → 延期→罚息→锁机→收回（内外一视同仁）
⑩ 到期转让   → 残值转让给客户·账务切换·资产出账
⑪ 月度结账   → 报表包·经营分析报告·管理费·每月5号分配(50现金/50滚存·留存≥20万)
⑫ 复盘复投   → BI/PDCA·回收资金滚动投新设备 ↺
```

每一步的详细触发/角色/单据/异常见第三部分；跨步的状态见第四部分。

## 第三部分 · 子流程详解（12 条）

> 统一格式：触发 → 角色 → 输入 → 步骤 → 系统动作 → 产出（单据/凭证）→ 异常/逆向 → **闭环校验点**。

### 流程 1 · 供应商开发与谈判
- **触发**：新品类立项 / 现有品类需增备选供应商。
- **角色**：供应链。
- **步骤**：定品类 → 收集≥2家 → 四维评估（品质/服务/价格/付款）→ 下场做 BOM/泵表估真实成本 → 按谈判清单议价谈账期 → 入供应商库。
- **系统动作**：建供应商档、存四维评分、存 BOM、记账期↔回报联动测算。
- **产出**：供应商档、谈判条件清单、（可选）框架协议。
- **异常/逆向**：恶意抬价 → 引入低价家、标记；供应商淘汰 → 状态置"停用"留痕。
- **闭环校验点**：每品类供应商 ≥2 家（否则亮"单一依赖"灯）；集采价 vs 市场价必录（否则报价测算缺输入）。

### 流程 2 · 报价与定价
- **触发**：客户询价 / 新合同立项。
- **角色**：供应链（提资料）+ 财务（定口径）。
- **输入**：设备市场价、集采成本、**月替代人工价值(月节省·价值定价核心输入)**、客户类型（目标 IRR）、供应商首付比例、租期、品类残值率。
- **步骤**：价值定价两校验【①品类准入 `市场价 ÷ 月节省 ≤ 18 个月`；②客户净收益 `月节省 − 月租 > 0`】→ 速算系数出**起价建议** → **用真实集采成本/残值/账期重算层级①税后 IRR** → **本金回报 ≥ 目标 IRR 门槛校验**（不达标退回重算/放弃）。
  - 注：删除旧"≤市场价"口径（客户总付本就>市场价，差额=资金时间价值）；IRR 为税后口径（1%增值税+12%附加+5%小微所得税）。
- **系统动作**：规则引擎出月租/回报/现金流；不达标锁定"生成合同"按钮。
- **产出**：报价单（可转合同草稿）。
- **异常/逆向**：不达标 → 调集采价/首付/租期重算，或退回不做。
- **闭环校验点**：**投放审批以本金回报率(层级①)为准**；合同禁写"融资租赁"（字段校验）。

### 流程 3 · 客户准入与风控
- **触发**：新客户 / 新合同。
- **角色**：供应链 + 财务（授信）。
- **步骤**：评估生意是否真赚钱、现金流、稳定性 → 定品类限定 → 定授信/押金 → 风控评级。
- **系统动作**：风控档、评级、授信额度、押金规则。
- **产出**：客户档 + 准入结论。
- **异常/逆向**：不过 → 拒绝并留痕；评级下调 → 触发存量合同预警。
- **闭环校验点**：不可撤销长约与租期匹配；**先签约后采购**（无准入无合同）。

### 流程 4 · 签约与租金计划生成
- **触发**：报价达标 + 客户准入通过。
- **角色**：供应链录入 + 财务复核。
- **步骤**：录合同要素（客户/设备/租期/月租/押金/期末转让价/性质=分期收款销售）→ 电子签 → **系统自动生成租金计划表 N 期**。
- **系统动作**：生成 `rent_schedule` N 行（到期日/应收/状态），合同状态 = 收租中。
- **产出**：合同 + 租金计划表。
- **异常/逆向**：合同作废 → 整份红冲（限未采购）；变更（提前结清/续租）→ 变更单重算剩余期。
- **闭环校验点**：勾稽 `期数×月租 + 期末转让价 = 客户总付`（**不含押金**）；押金单独走保证金科目（收/退/期末抵转让价），不进客户总付净额。

### 流程 5 · 采购集采与应付
- **触发**：合同签约（先签约后采购）。
- **角色**：供应链下单 + 财务应付。
- **步骤**：绑合同下采购单 → 首付 → 验收 → 尾款（按谈成账期）。
- **系统动作**：`purchase_in` + 应付计划（首付/验收/尾款）→ 应付凭证；应付计入负债率。
- **产出**：采购单 + 应付凭证。
- **异常/逆向**：退货 → 采购红冲 + 应付红字；到货不符 → 拒收留痕。
- **闭环校验点**：**无合同不允许生成采购单**（防空置）；应付到期进现金流驾驶舱。

### 流程 6 · 入库投放与交付
- **触发**：采购到货。
- **角色**：供应链 / 现场。
- **步骤**：逐件编号建档（序列号/条码）→ 现场交付拍照留痕 → 起租 → 押金入账。
- **系统动作**：`asset` 建档、状态 采购→投放→在租；押金收款。
- **产出**：设备档 + 交付单（含现场照）。
- **异常/逆向**：交付争议 → 现场照留痕；未起租设备 → 亮"空置"灯。
- **闭环校验点**：设备状态机推进有据；起租日 = 租金计划首期起算日。

### 流程 7 · 月度收租与核销
- **触发**：租金计划表每期到期日 T-3 自动生成收租单。
- **角色**：财务（复核）+ 系统。
- **步骤**：系统生成收租单 → 客户付款 → 到账（微信/银行流水）自动匹配 → 核销 → 生成收入凭证。
- **系统动作**：`rent_bill` 生成→匹配→核销→`voucher`；未到账进逾期分流。
- **产出**：收租单 + 收入凭证。
- **异常/逆向**：收错/多收 → 红冲/退款单；提前结清 → 剩余期一次性计。
- **闭环校验点**：**"钱该动没动"亮灯**（到期未生成/已收未核销）；已核销期回填凭证号。

### 流程 8 · 逾期处置（三步走）
- **触发**：收租单逾期。
- **角色**：财务催收 + 供应链配合。
- **步骤**：① 延期（了解情况）→ ② 罚息（超延期）→ ③ 锁机/收回（持续未付，物权在我方）。**内外一视同仁**。
- **系统动作**：`overdue_case` 状态机；自动短信/升级人工/生成罚息单/收回单。
- **产出**：逾期案 + 罚息单/收回单。
- **异常/逆向**：还款 → 案关闭、恢复；收回设备 → 资产状态转"收回待处置"、评估残值二次流转。
- **闭环校验点**：每逾期案必有"裁决人 + 下一步 + 期限"；收回设备进空置/再投放闭环。

### 流程 9 · 到期转让 / 处置
- **触发**：合同到期前 30 天提醒。
- **角色**：供应链谈 + 财务账务。
- **步骤**：转让报价（市场价10%/30%）→ 客户签署 → 账务切换（残值收入凭证 + 资产出账）。
- **系统动作**：`transfer_order`；资产状态 在租→待转让→已转让；计税并入价款。
- **产出**：转让单 + 残值凭证。
- **异常/逆向**：客户不买 → 收回再租/处置二手；转让价异常低 → 税务核定风险亮灯（禁名义价）。
- **闭环校验点**：合同随转让关闭；设备退出在租池；转让收益进利润。

### 流程 10 · 维保 / 盘点
- **触发**：报修 / 预防维保计划 / 月度盘点。
- **角色**：现场（移动端）。
- **步骤**：工单 → 扫码定位 → 处理/拍照 → 回传更新台账；盘点账面带出只录差异。
- **系统动作**：`maintenance`；质保内转供应商；盘点账实差异生成调整。
- **产出**：维修工单 + 盘点单。
- **异常/逆向**：账实不符 → 盘盈亏调整（走单据，不直改台账）。
- **闭环校验点**：质保期/责任方判定；盘点差异必有调整单闭合。

### 流程 11 · 月度结账、报表与分配
- **触发**：月初（财务日历）。
- **角色**：财务 + 老板/GP。
- **步骤**：1日待人工结账 → 2日报表包自动生成（六件套）→ 3日核对 → 5日过《经营分析报告》七节、定改进、执行分配。
- **系统动作**：报表包 + AI 起草综述（规则引擎出数字）；管理费阶梯计提；分配单（50%现金/50%滚存，留存≥20万）；分配表按角色可见。
- **产出**：月度报表包（Excel）+ 经营分析报告（Word）+ 分配单。
- **异常/逆向**：当期无可分配 → 不分配、结转；年终按实际清算多退少补。
- **闭环校验点**：报表口径与凭证同源；分配后**留存 ≥ max(20万, 未来3月供应商净应付)**；**账期兑付缺口预警**（payable 到期 vs 对应设备回款/空置+可动留存，缺口<0 亮红灯+裁决人+补款来源）；分配表权限隔离；`distribution/run` 按 period 幂等。

### 流程 12 · 凭证与双套账
- **触发**：任何业务单据确认。
- **角色**：财务 + 系统。
- **步骤**：单据 → 自动生成凭证 → 两套账（税务口径"分期收款销售" / 经营口径"三层回报"）各记。
- **系统动作**：`voucher` + `ledger_book`（双账）；500万营收红线监控。
- **产出**：凭证 + 双账台账。
- **异常/逆向**：红冲连锁（数量错整单红冲/单价错成本调整/已付应付红字）；锁账后"上期调整"行承接。
- **闭环校验点**：**钱只被单据改**；红冲必过"影响清单"确认；营收逼近500万预警。

## 第四部分 · 状态机（每个对象的"命"）

| 对象 | 状态流 | 逆向/异常 |
|---|---|---|
| **设备 asset** | 采购 → 投放 → 在租 → 待转让 → 已转让｜(收回待处置 → 再投放/二手) | 收回、报废 |
| **合同 contract** | 草稿 → 生效(收租中) → 到期转让 → 关闭 | 作废(红冲)、提前结清、续租 |
| **收租单 rent_bill** | 待生成 → 待收 → 已核销｜逾期 | 红冲/退款 |
| **逾期案 overdue_case** | 延期 → 罚息 → 锁机/收回 → 关闭 | 还款恢复 |
| **采购单 purchase_in** | 下单 → 首付 → 验收 → 尾款结清 | 退货红冲、拒收 |
| **转让单 transfer_order** | 待转让 → 已签署 → 账务完成 | 客户不买→收回 |

## 第五部分 · 单据流转与业财一体凭证链

```
签约 ─► 租金计划表(N期)                         [合同→计划]
采购 ─► 采购入库单 ─► 应付凭证(首付/账期)         [业→财]
到期 ─► 收租单(自动) ─签收─► 收入凭证 ─► 核销应收  [业→财→核销]
逾期 ─► 逾期案 ─► 罚息单 / 锁机 / 收回单           [风控闭环]
租满 ─► 转让单 ─► 残值收入凭证 + 资产出账          [资产退出]
月底 ─► 管理费计提 ─► 分配单(现金/滚存) ─► 月度报表 [分配闭环]
逆向 ─► 红冲/退租/调整/锁账补导(全部走单据·过影响清单确认)
```
**铁律**：钱只能被单据改；每分钱有来处去处；"钱该动没动"亮灯；逆向路径完整（ERP 死穴全在逆向）。

## 第六部分 · 操作流 SOP（按角色的日常）

### 6.1 供应链管理（李工）
- **每周**：跑 ≥1 家新供应商比价；下场泡工厂/客户现场补 BOM 与替代人工数据。
- **接需求**：客户需求 → 报价测算（找财务定口径）→ 出方案。
- **签约后**：录合同 → 触发采购（先签约后采购）→ 跟进入库投放。
- **配合催收**：逾期案分派到手时跟进现场。
- **效率三问落地**：扫码定位设备（不打字）、合同要素预填（不重复录）、卡上原地操作（不跳页）。

### 6.2 财务
- **月度结账日历**：1日结账 → 2日报表包 → 3日核对 → 5日过报告+分配。
- **日常**：报价核算口径维护；收租到账核销；凭证复核；应付到期提醒。
- **合规**：盯合同不含"融资租赁"；盯营收 500 万红线；分配后留存 ≥20万。

### 6.3 老板 / GP（小洪）
- **审批**：投放审批（本金回报≥目标；300万内自主，超额协商）。
- **月度**：5日过《经营分析报告》，定下月改进（入 PDCA）。
- **决策**：品类扩张（18个月阈值）、供应商淘汰、独立团队触发（1000万+30%）。

### 6.4 每日/每月节奏一览
| 频率 | 供应链 | 财务 | 老板/GP |
|---|---|---|---|
| 每日 | 跑供应商/现场、录单、催收 | 到账核销、异常处理 | 看驾驶舱红点 |
| 每周 | 比价、BOM、拓客 | 应收应付对账 | 审批 |
| 每月 | 需求汇总 | 结账/报表/分配 | 过报告/定改进 |

## 第七部分 · 闭环校验点总表（优化到 100 的清单来源）

> 每条流的"正向出口 + 逆向路径 + 亮灯"三件齐了才算闭环。系统优化即：把下列每一条在 UI/规则里落全。

| # | 流程 | 正向出口 | 逆向路径 | 亮灯/校验 |
|---|---|---|---|---|
| 1 | 供应商 | 入库、可比价 | 淘汰留痕 | 每品类≥2家 |
| 2 | 报价 | 达标转合同 | 不达标重算/放弃 | 本金回报≥IRR、禁"融资租赁" |
| 3 | 风控 | 准入、授信 | 拒绝/降级预警 | 先签约后采购 |
| 4 | 签约 | 生成租金计划 | 作废红冲/变更 | 勾稽=客户总付 |
| 5 | 采购 | 应付、入库 | 退货红冲 | 无合同不采购 |
| 6 | 投放 | 起租 | 空置亮灯 | 起租日=首期 |
| 7 | 收租 | 核销、凭证 | 红冲/退款 | 钱该动没动亮灯 |
| 8 | 逾期 | 关闭/恢复 | 锁机/收回→再流转 | 裁决人+期限 |
| 9 | 转让 | 关闭合同、资产出账 | 客户不买→收回 | 禁名义价、税务核定 |
| 10 | 维保盘点 | 台账更新 | 盘盈亏调整单 | 差异必闭合 |
| 11 | 结账分配 | 报表+分配 | 无利不分/年终清算 | 留存≥20万、权限隔离 |
| 12 | 凭证双账 | 凭证、双账 | 红冲连锁/锁账补导 | 钱只被单据改、500万预警 |

## 第八部分 · 深度拆解（Drill-down 维度 → 落到系统功能）

> 原则：每个核心名词都要能"拆开看"——拆到配件、拆到成本、拆到多维画像。下面每张拆解表都对应一块要新增/加深的**系统功能**。

### 8.1 设备（机器）拆解 —— 拆到配件与成本
| 拆解层 | 内容 | 落到系统功能 |
|---|---|---|
| **配件树 BOM（多级）** | 设备 → 总成/模块 → 部件 → 元器件。例：播种墙 = 钢构框架 + 电控系统 + 传感模组 + 传动 + 其他；每节点含 数量/单价/供应商/寿命/质保/可维修性 | 设备详情页新增「**配件树(BOM)**」子面板，可逐级展开；配件本身也是"物"，可下钻、可挂供应商 |
| **成本拆解** | 采购成本 = Σ 配件成本；到货成本 = 采购+运输+安装；对比集采价识别虚高 | 「**成本拆解**」环形/瀑布图：钢构¥5,200/电控¥2,600/传感…/运输安装 |
| **残值拆解** | 整机残值 = Σ 部件残值×各自折旧曲线（钢构保值、电控贬值快）→ 决定期末转让定价 & 要不要收回二次流转 | 「**残值构成**」+ 折旧曲线；转让定价参考 |
| **故障/维保拆解** | 故障率按配件统计 → 高故障配件预警 → 备件常备清单 → 质保责任归属（哪家供应商的配件） | 「**故障档案**」按配件；备件清单；质保倒计时 |
| **收益拆解** | 单台：累计收租/月租分摊/在租天数/空置天数/单台回报率 | 「**单台收益**」卡；空置天数亮灯 |

### 8.2 供应商拆解 —— 拆到供货矩阵、价格构成、履约多维
| 拆解层 | 内容 | 落到系统功能 |
|---|---|---|
| **供货矩阵** | 一家供应商供哪些整机/配件（不只整机）→ 支持"整机集采 vs 配件自采组装" | 供应商详情「**供货矩阵**」（按品类/配件）；配件级可挂多供应商比价 |
| **价格构成** | 报价 = 材料+加工+利润；对比 BOM 识别虚高 | 「**价格构成**」拆解 + vs BOM/市场价 |
| **履约评分（多维雷达）** | 品质(故障/退货率)、交期(准时率)、服务(响应/到场)、价格(vs市场/BOM)、账期(首付比例) → 加权总分 → 主供/备供排序 | 「**履约雷达**」+ 加权总分 + 自动排序 |
| **账期与返利** | 首付/验收/尾款分层、现金折扣、阶梯返利、维保费返点 | 「**账期与返利**」+ 账期↔回报联动 |
| **关系生命周期** | 接触 → 试样 → 入库 → 主供/备供 →（淘汰）每阶段留痕 | 供应商 pipeline 状态 |

### 8.3 客户拆解 —— 拆到信用画像、价值 LTV、风险敞口
| 拆解层 | 内容 | 落到系统功能 |
|---|---|---|
| **信用画像（多维雷达）** | 盈利能力/现金流/经营稳定/历史履约(逾期次数天数)/行业风险 → 评级 A/B/C → 授信额度/押金/目标 IRR | 客户详情「**信用画像雷达**」+ 评级 |
| **价值 LTV** | 累计合同数/累计收租/累计利润/在租设备/续租率 → 客户价值分层（大客户从优定价） | 「**客户价值**」分层标签（战略/普通/观察） |
| **风险敞口** | 单客户在租设备总额/应收总额/逾期额 → 集中度预警（初期依赖云仓，集中度高） | 「**风险敞口**」+ 客户集中度看板 |
| **下钻** | 客户 → 名下合同 → 每合同租金计划 → 每台设备 | 层层下钻 |
| **生命周期阶段** | 意向 → 准入 → 在租 →（逾期）→ 到期 → 续租/流失 → 复盘 | 阶段条 + 阶段对齐策略（详见第九部分 CRM） |

### 8.4 还能更深的（我提的第 3 点）
| 对象 | 拆解 | 落到系统功能 |
|---|---|---|
| **合同 · 每期租金构成** | 每期 ¥6,720 = 本金摊 + 资金成本 + 差价分摊 + 残值预留 → "这份合同每期赚在哪" | 合同页「**租金构成**」拆解条 |
| **单笔盈亏（成本归集）** | 每合同/每设备真实盈亏 = 收租 − 集采成本 − 资金成本 − 运维 − 坏账拨备 − 管理费分摊（抄 Baseplan 项目级成本归集） | 合同/设备「**单笔 P&L**」 |
| **回报四源**（利润维度）+ **三层杠杆**（资金结构维度）| 四源=集采差价X%+资金时间价值Y%+价值定价Z%+**残值回收W%**（四者之和=总税后IRR，可勾稽）；三层=本金/供应商/融资杠杆，两者是不同维度别混 | 驾驶舱「**回报归因**」 |
| **现金流** | 应收按到期分层 + 应付按到期分层 + 净现金流预测曲线 + 三层杠杆占用 | 现金流驾驶舱加"净现金流曲线" |
| **BI 多维矩阵** | 在租率/回报/账龄 可按 品类×客户×供应商×设备×时段 下钻 | BI 矩阵四象限 + 下钻 |
| **人（员工）** | 提成拆到"每单降本/成交贡献"；任务拆到角色 | 花名册页提成拆解 |
| **项目/组织** | 多项目独立核算 → 每项目 P&L 独立（保密隔离） | 项目维度 P&L |

## 第九部分 · 客户 CRM 与全生命周期（潜在客户长期跟进 · 规模化 100+）

> 用户点出的关键缺口：**潜在客户 ≠ 成交客户**。现在的"客户页"是成交后视角，缺了成交前的**销售管道 + 长期跟进**；且要扛得住 100+ 客户/供应商的规模。本部分把客户模块升级为真正的 CRM，架构不变、在客户模块内做深。

### 9.1 客户全生命周期（销售管道 Pipeline）
```
线索 Lead → 潜在客户 Prospect → 跟进中 Following → 商机 Opportunity → 报价 → 风控准入 → 成交签约 → 在租客户 → 续租/流失 → 复盘
   └─────────────── 业务(BD)长期跟进、多次触达 ───────────────┘        └── 运营/财务 ──┘
```
- **成交前（业务/BD 负责）**：线索池 → 跟进（每次触达留记录）→ 培育商机 → 转报价。**不是每个来的都服务**（老板铁律：只服务确定性客户），业务负责把"潜客"养成"确定性商机"。
- **成交后（运营/财务负责）**：风控准入 → 签约 → 在租 → 收租 → 续租/流失。
- 一个客户在系统里只有一条命，**symbol=客户主键**串起成交前后（对齐图南"一只股一条命"工作流思想）。

### 9.2 潜在客户与跟进（CRM 核心新增）
| 能力 | 说明 | 系统功能 |
|---|---|---|
| **客户分型** | 线索/潜客/商机/成交/流失；成交客户再分 战略/普通/观察 | 状态标签 + 阶段条 |
| **跟进记录时间线** | 每次电话/拜访/微信 留记录（时间/方式/内容/结果/下一步） | 客户详情「**跟进时间线**」 |
| **下次跟进提醒** | 每个潜客设"下次跟进日"，到期进业务待办、逾期未跟进亮灯 | 「**跟进待办**」队列 + 亮灯 |
| **商机预估** | 预计品类/设备/金额/成交概率/预计成交月 | 商机卡；管道加权预测 |
| **培育策略** | 按阶段给动作建议（潜客→约现场看设备；商机→出测算方案） | 阶段对齐动作 |
| **转化** | 商机 → 一键转"报价测算" → 达标 → 转"风控准入" → 签约 | 管道各阶段一键流转 |

### 9.3 规模化（100+ 客户/供应商怎么管）
> 现在的"详情页 demo"不够——上量后靠的是**列表/看板/筛选/搜索/分层**。

| 能力 | 说明 | 系统功能 |
|---|---|---|
| **客户池列表** | 全量客户表：搜索、按 阶段/评级/行业/负责业务/价值分层/应收账龄 多条件筛选、排序、分页 | 「**客户池**」列表页（支撑 100+） |
| **销售管道看板** | Kanban：线索/跟进中/商机/已成交/流失 分列，卡片可拖动推进阶段 | 「**销售管道**」看板 |
| **保存的分群** | 常用筛选存为"我的分群"（如"云仓系高价值"、"30天未跟进潜客"） | 分群快捷入口 |
| **负责人分配** | 每客户绑负责业务；业务只看自己的 + 客户池公海（保密隔离） | 负责人字段 + 公海认领 |
| **批量动作** | 批量改阶段/派跟进/发提醒 | 批量操作 |
| **客户集中度** | 100+ 客户下的集中度、账龄分布、评级分布总览 | CRM 概览看板 |

### 9.4 供应商同理（pipeline 规模化）
供应商也从"详情 demo"升级为**供应商池 + 状态管道**（接触中/试样/已入库/主供/备供/淘汰）+ 多条件筛选（品类/评分/账期/是否主供）+ 供货矩阵，支撑 N 家供应商比价管理。

### 9.5 落到 UI 的模块升级（架构不变，模块做深）
- **客户模块**：由单一"客户详情"升级为三视图 —— ①**客户池**(列表/筛选/100+) ②**销售管道**(看板/潜客跟进) ③**客户详情**(信用画像+LTV+风险敞口+跟进时间线+名下合同下钻)。
- **供应商模块**：升级为 ①**供应商池**(列表/筛选) ②**供应商详情**(供货矩阵+价格构成+履约雷达+账期返利)。
- **设备模块**：设备详情加 配件树BOM + 成本拆解 + 残值构成 + 故障档案 + 单台收益。
- 新增 **业务(BD)角色**：负责成交前跟进；与供应链/财务分工（供应链偏上游+交付，业务偏获客+跟进）。

## 附：优化到 100 的原则
1. **每条流都要能"走回头路"**（逆向路径进 UI，不只走 happy path）。
2. **每个"该动的钱/该做的事"都要亮灯**（不靠人记）。
3. **每个名词可下钻、每个干活页有任务来源+流程条**（七律）。
4. **数字全程规则引擎、带数据溯源；AI 只起草**。
5. **保密隔离贯穿**（成本价/账期/分配按角色与项目隔离）。
