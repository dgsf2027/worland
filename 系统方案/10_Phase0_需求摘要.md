# 沃朗科技租赁板块 · Phase 0 需求摘要（立项确认书）

> 版本：v1.0（待用户确认）　|　日期：2026-08-08　|　流程：F1 陪同车 · Phase 0
> 用途：Phase 0 需求澄清成果，经用户确认后进入 Phase 1（DESIGN_DOC）。

---

## 一、项目一句话
在智慧园区平台内新建「**租赁板块**」，管理沃朗科技（仓储设备租赁·有限合伙）的**业/财/人/事/物 + 时/钱/风/关系/保密**全维度，与园区小卖账房是同平台兄弟板块。

## 二、给谁用（用户角色）
| 角色 | 用途 |
|---|---|
| 老板/GP（小洪） | 驾驶舱、审批、月度过报告、决策 |
| 供应链管理 | 供应商开发比价、设备台账、合同、下场 |
| 业务(BD) | 潜客长期跟进、销售管道、成交 |
| 财务 | 报价核算、凭证双账、月度结账分配、报表 |
| LP 出资人 | 不操作系统，只收《月度报表》（按角色发放） |

## 三、现在怎么解决（替代方案）
目前靠人工 Excel 台账 + 会议纪要 + 设立方案书；无系统、无业财一体、无风控亮灯、无 CRM 跟进。

## 四、必做（Must-have） vs 锦上添花（Nice-to-have）
**Must-have**：供应商池/CRM 客户管道/逐件设备台账/报价测算器/合同+租金计划/采购应付/收租核销/逾期三步走/到期转让/凭证双账/现金流分配/月度报表/任务审批/风控亮灯/权限保密隔离。
**Nice-to-have（后置）**：BI 多维矩阵深钻、AI 月报/合同抽取、移动端扫码盘点、维保工单、二手处置市场。

## 五、敏感字段（单位先统一 · 审计教训）
- **设备计价单位**：元；**1 台播种墙 = 市场价 20 万 / 集采 18 万**（真相源口径，禁再出现 9千/台的 20× 歧义）。
- **建模口径（已锁定）**：**逐件建档**（每台一条记录+序列号），**合同挂 N 台**。
- 金额字段 schema/代码注释/API 三处标单位；月租/回报/税率口径以《设立方案书 V14.0》为准。

## 六、爆炸半径（影响哪些现有系统）
- 新板块，独立库表前缀 `yc_rent_`，**不改**园区小卖账房的表。
- 复用平台账号/组织/权限模型、导入中心内核、业财一体单据链内核、AI 透明四件套、报表 BI 框架。

## 七、已锁定决策（本会话）
| 维度 | 决策 |
|---|---|
| 架构 | 智慧园区平台下租赁板块，先独立后嵌入 |
| 技术栈 | Spring Boot 2.7 + Vue3 + MySQL8 + SSO（同小卖账房） |
| 交付 | 业财人事物全量规划、分里程碑，**目标管理·从0驱动到上线** |
| 里程碑 | 冲刺0 → M1业务地基 → M2收租 → M3财务分配 → M4转让资产 → M5事人BI |
| 设备口径 | 逐件建档，合同挂 N 台 |
| 初始数据 | Excel 导入中心 + 手工录入 都做 |
| 设计DNA | 园区小卖账房设计七律 + 逆向闭环 + 保密隔离 |

## 八、待确认卡点（进 Phase 1 前）
1. **SSO 对接现实**：园区小卖账房自身仍用 `X-User` 占位头、平台 SSO 尚未接通。故"现在就对接 SSO"可能无可对接对象 —— 需确认平台 SSO 是否已就绪 / 有无接口文档与测试账号；否则先占位头独立跑、平台就绪再换。
2. **上线到 prod**：属对外/不可逆红线，由用户按"部署"显式放行，不自动。

## 九、不做清单（本期边界）
- 不做多租户 SaaS 售卖（是平台内板块，非独立产品）。
- 不做出资人实时门户（改月度报表按角色发放）。
- 不做融资租赁牌照业务（合同禁写"融资租赁"，按分期收款销售）。
- 不自建登录（复用平台 SSO）。

## 十、Phase 0 出口
用户确认本摘要 → 进 Phase 1，产出 `DESIGN_DOC.md`（架构/数据模型/API/风险）+ 必要 ADR，再过 Phase 1.5 设计评审委员会。
