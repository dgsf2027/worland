## 核心逻辑一图流

```
上游设备工厂  →→→  沃朗科技（独立有限合伙·设备物权在手）  →→→  下游客户
（货架/阁楼/播种墙）    数智云仓任GP·小洪运营执行            （云山快仓 + Dpark园区租户）
  集采压价10%              租满即转让·月度收租分红              按"节省的价值"定价·分期
  谈账期(首付越低回报越高)   赚:集采差价+资金时间价值+价值定价空间+残值   比市场省·期末低价买断
```

## 三句最重要的话

1. **我们卖的不是"便宜设备"，是"客户省下的价值 + 轻资产 + 分期"**——按承租方"18 个月能回本"来定价，不是成本加成。
2. **三份钱叠加**：① 集采差价（约 10%）② 资金时间价值（分期）③ 价值定价空间；外加期末**残值转让**。
3. **两条纪律**：① 先签约后采购、逾期"延期→罚息→收回"三步走、内外一视同仁；② 上下游价格账期严格保密、项目独立核算。

## 关键事实卡（与《设立方案书》对齐）

- **架构**：有限合伙。GP＝数智云仓（20万/10%）；LP＝小洪（60万/30%，运营执行）、刘总（70万/35%）、其他（50万/25%）。首期 **200 万**。
- **品类**：首期只做**货架（含阁楼）、标准播种墙**；后续按 `市场价 ÷ 月替代人工价值 ≤ 18 个月` 阈值扩品类。
- **客户**：云仓体系（云山快仓）为主，Dpark 园区租户为辅。
- **交易结构**：播种墙 **3 年** / 期末转让市场价 **10%**；货架 **5 年** / 期末转让市场价 **30%**。
- **目标税后 IRR**：云山快仓 **25%**、其他客户 **30%–35%**、新品类 35%+。
- **分配**：每月 5 日，可分配利润 **50% 现金 / 50% 滚存**，账面留存 ≥ 20 万。
- **税务**：按"分期收款销售货物"处理（**不得写"融资租赁"**）；小规模纳税人，增值税 3% 减按 1%，营收峰值约 305 万，全程可留在小规模。
- **十年推演（基准）**：股东总价值约 **665 万（3.32 倍）**，累计投放设备约 1,569 万（7.8 倍）。
