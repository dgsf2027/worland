# 资产定位与三家地图配置

## 无密钥先用

入口：资产管理 → 资产台账 → 资产定位；资产详情也有入口。每条台账代表一批同规格资产，保存一个位置，不是连续追踪，也不是每件实物各自的 GPS 位置。

1. 在资产现场用手机打开本站（HTTPS），点“使用现场位置”，允许浏览器定位。该功能不需要地图 Key；依赖设备与浏览器定位服务，拒绝授权、网络/设备不支持时会提示失败，不会用 IP 位置替代。
2. 核对精度和地点，补充位置说明，点“保存位置”。仅老板、供应链、业务可修改；其他已登录角色可查看和导航。
3. 高德、百度“查看”和“导航”使用官方 URI，不需要申请 Key。电脑上可能需要填写出发地；手机能否唤起地图 App 取决于安装情况和浏览器限制。
4. 不在现场可打开官方选点工具，复制“经度,纬度”回到系统，选择正确坐标系后应用。高德/腾讯用 GCJ-02，百度用 BD-09，GPS 用 WGS-84。百度游客/未认证开发者拾取器只保留两位小数，不适合资产定位，请认证后获取精确点，或改用现场定位。外部工具不能自动回填本站。

2026-11-10 实测：高德、百度免 Key 地点 URI 在 Edge 中均能显示指定广州测试点及导航入口。腾讯无 Key URI 本机跳转后目标页连接失败，不能视为可用；系统在腾讯 Key 为空时不提供伪可用导航链接。官方拾取器可访问，但第三方工具自身可能要求登录/实名；不能把页面可访问当作精确坐标可获取。

同日使用用户提供的高德 Web 端 Key 和安全码完成本机真实联调：地图显示、地址搜索及反查返回成功。保存请求使用模拟后端验证，未修改线上资产。配置保存在本机被忽略的 `.env.local`；安全码经检查不在前端构建产物中。真实值不随 Git 推送，生产环境仍须单独配置。

## 申请后开启内嵌地图

在各平台建立自己的应用，申请浏览器/JavaScript 类型 Key，限定实际部署域名和测试域名，不使用文档示例或他人的 Key。各平台的认证、服务开通、配额/商业许可按其控制台要求办理。

| 平台 | 配置 | 接入能力 |
| --- | --- | --- |
| 高德 | `VITE_AMAP_KEY` + `AMAP_SECURITY_JS_CODE` | JS API 2.0 选点、地址查询；安全码仅留在 nginx 代理 |
| 百度 | `VITE_BAIDU_MAP_AK` | JS API 4.0 选点、地址查询 |
| 腾讯 | `VITE_TENCENT_MAP_KEY` | GL JS API 选点、地址查询、URI 查看与导航（referer 使用自己的 Key） |

生产环境填写 `deploy/.env`（以 `.env.example` 为模板，不提交真实值）。Compose 将三家浏览器 Key 传入前端构建，将高德安全码仅传给前端 nginx 运行容器：

```sh
docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env build worland-web
docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env up -d worland-web
```

首次上线本功能还需按现有部署流程构建并更新 `worland-server`，由 Flyway 执行 V126 新增定位字段；上线前照常备份数据库。先更新后端，再更新前端。旧资产坐标为空，不推测、不批量写入位置。

高德安全代理默认是当前站点 `/_AMapService`。镜像启动脚本生成代理配置，转发到高德固定域名并追加安全码；没有安全码时返回 503。网关必须把 `/_AMapService/` 路由到 `worland-web`（整体域名反代到该容器时无需额外规则）。安全码不能使用 `VITE_` 前缀，不能写入源码或浏览器配置。若已有独立安全代理，将 `VITE_AMAP_SERVICE_HOST` 设置为它的完整地址，路径必须以 `/_AMapService` 结尾，并按高德要求配置跨域。

本机开发：浏览器 Key 和 `AMAP_SECURITY_JS_CODE` 放入被 Git 忽略的 `frontend/.env.local`，Vite 开发服务器通过同源代理追加安全码；也可用 `VITE_AMAP_SERVICE_HOST` 指定已有安全代理。安全码始终不进入浏览器构建。修改浏览器 Key 后必须重启 Vite/重新构建静态资源；更换生产高德安全码需重建运行容器。Key 的域名白名单还需包含开发访问域名。

## 验收和数据口径

- 三家地图按需加载；地址搜索失败不覆盖已有选点。地图选点/现场定位仅生成草稿，保存后才更新台账；取消不写入。
- 数据库统一保存 GCJ-02（七位小数）。浏览器 WGS-84 与百度 BD-09 在前端转换；切换地图不重复转换已保存坐标。转换适用于普通资产定位，保存小数位数不代表实测精度，现场精度按浏览器返回值展示。
- 资产的原有“存放位置”文字、数量、出租信息不受更新定位影响。清除定位保留操作人和时间；更新/清除均有审计。未登录的二维码公开页不展示坐标。
- 填入 Key 后逐家检查地图加载、点击选点、地址搜索、保存重开、导航，并核对同一地标；此仓库的模拟 SDK 回归不能代替真实 Key 和手机实地验收。
- 没有申请密钥时，不应对外宣称三家内嵌地图均已开通。当前免密钥工作流可先使用，三家 SDK 接入与配置入口已准备好。
